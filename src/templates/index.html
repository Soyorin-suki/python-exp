🏠 房价预测系统

基于 Kaggle 开源数据集，使用 Flask + sklearn / PyTorch 构建的交互式房价预测系统。

推荐流程: 1. 上传/生成 → 2. 清洗 → 3. 训练 → 4. 预测 → 5. 可视化
  • 数据上传 上传 CSV 或 XLSX 格式的数据集文件
  • 生成测试数据 生成带噪声的合成数据集，用于快速测试
  • 数据清洗 缺失值填充、异常值处理、数据标准化
  • 模型训练 选择 sklearn (LinearRegression) 或 PyTorch (全连接神经网络) 进行训练
  • 房价预测 选择已训练模型，输入特征值，获取预测结果
  • 数据可视化 直方图、散点图、相关性热力图
